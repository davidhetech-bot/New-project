Music Player Demo

Files added:
- music-player.html
- music-player.css
- music-player.js

How to use
1. Open `music-player.html` in a browser (double-click or drag to browser).
2. For best results run a local server:

Windows (PowerShell):

```powershell
py -m http.server 8000
# or
python -m http.server 8000
```

Then open http://localhost:8000/music-player.html

Notes
- The demo uses sample MP3 files from SoundHelix (public examples).
- Replace tracks in `music-player.js` with your own files if desired.
- Let me know if you want features: gapless, waveform, visualizer, or file upload.
